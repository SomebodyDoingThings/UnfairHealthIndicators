a modified version of the original [Health Indicators](https://modrinth.com/mod/health-indicators) mod

## differences
- you can see **all** healthbars *(including players)* through walls
- you can see healthbars for invisible entities
- it works on 26.3 (the original has not updated as of september 23rd, 2026)
